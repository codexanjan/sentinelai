# Validation — Sentinel 0.4.0 beta

Android release build succeeded. Eleven JVM test methods passed (8 existing core, 3 new recovery/copy/clock tests), with zero failures. Core tests cover RFC6238/4226 vectors, strict provisioning, encryption and backup roundtrip/password/tamper behavior. New tests cover local metadata roundtrip, v1 read compatibility, fresh-copy timing at period boundaries and clock-change detection in both directions. Release lint completed with 0 errors and 19 warnings; these are retained in the source build report and are not represented as a clean-warning result.

The optimized APK is 4,721,563 bytes and has a verified APK v2 signature using the existing Sentinel release key. Signing credentials are excluded from source and release archives.

Web checks passed: no optional feature-library requests before the landing/demo; landing and demo still work with every vendor library blocked; static intro remains visible on module failure and the old waiting card is absent; offline reopening; switch alignment, folder CRUD, favorite/recovery actions, deletion, manual enrollment, real QR image enrollment, simulated camera scan/track cleanup, duplicate-key rejection, encrypted metadata persistence, mobile overflow checks, 18 RFC6238 vectors, portable-backup Unicode/tamper handling and export/restore. Fresh-copy tests verify waiting through the boundary and no clipboard write after lock.

One local startup measurement was 2,006 ms while an Android build was running. This is a local observation, not a universal latency promise or a production before/after benchmark. Real vault Argon2id settings remain unchanged.

Images show public demo accounts. Native 0.4.0 was installed and launched on a read-only Android 37 emulator. Its sign-in screen, public demo vault and Recovery studio rendered successfully; actual screenshots are included. Focus mode hid both codes until one account was revealed, leaving the other hidden. Sending the app to the launcher and reopening cleared the demo and returned to sign-in. The emulator had a System UI response failure during startup before restarting that system dialog; no general native startup speed claim is made. Physical-device camera/biometric/credential behavior, accessibility, real account login and independent security review remain outstanding. Local and web functions are implemented; no claim of complete production security certification is made.
